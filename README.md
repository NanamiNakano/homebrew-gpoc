# NanamiNakano Gpoc

## How do I install these formulae?

`brew install nanaminakano/gpoc/<formula>`

Or `brew tap nanaminakano/gpoc` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nanaminakano/gpoc"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
